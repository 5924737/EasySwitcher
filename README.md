# easy-switcher-ng

Исправляет текст, набранный не в той раскладке. Набрали `ghbdtn` вместо «привет» — нажмите **Delete**: слово сотрётся, раскладка переключится, и слово напечатается заново.

| Клавиша | Действие |
|---|---|
| Delete | исправить последнее слово |
| Shift+Delete | исправить всю фразу (с последнего клика мышью, Enter или стрелок) |
| Delete ещё раз | вернуть как было |

Если перед Delete ничего не набирали, Delete работает как обычная клавиша.

Замена для `easy-switcher` 0.4, который под нагрузкой терял буквы.

## Требования

- Ubuntu 24.04 или похожий дистрибутив, GNOME на **X11** (не Wayland). Проверить: `echo $XDG_SESSION_TYPE` → `x11`
- `python3-venv`: `sudo apt install python3-venv`
- Переключение раскладки по Ctrl+Tab. Если у вас другая комбинация, поменяйте `switch_keys` в настройках.

## Установка

Запускайте **без sudo** — пароль скрипт спросит сам, а программа ставится для вашего пользователя.

```bash
./easy-switcher-ng-setup.sh install
```

`easy-switcher-ng-setup.sh` — самодостаточный установщик: программа, настройки, автозапуск и правило udev встроены в него. Для переноса на другой компьютер достаточно одного этого файла.

Другие команды:

```bash
./easy-switcher-ng-setup.sh status      # работает ли + последние записи журнала
./easy-switcher-ng-setup.sh uninstall   # удалить (настройки остаются)
./easy-switcher-ng-setup.sh help        # инструкция
```

## Управление

```bash
systemctl --user stop    easy-switcher-ng   # выключить
systemctl --user start   easy-switcher-ng   # включить
systemctl --user restart easy-switcher-ng   # после правки настроек
journalctl --user -u easy-switcher-ng -f    # журнал в реальном времени
```

## Настройки

Файл `~/.config/easy-switcher-ng/config.toml`:

| Параметр | По умолчанию | Что значит |
|---|---|---|
| `correct_key` | `KEY_DELETE` | клавиша исправления (`KEY_PAUSE` и т.п.) |
| `switch_keys` | `KEY_LEFTCTRL+KEY_TAB` | комбинация смены раскладки, как в Настройки → Клавиатура |
| `reverse_mode` | `false` | `true` — без Shift исправляется фраза, с Shift — слово |
| `switch_timeout_ms` | `3000` | максимум ожидания смены раскладки |
| `settle_ms` | `20` | дополнительная пауза перед печатью |
| `inject_delay_ms` | `5` | пауза между символами |

## Как устроено

- Все нажатия клавиатуры проходят через программу по порядку: физическая клавиатура захватывается, а события отдаются в систему через виртуальное устройство uinput. Поэтому то, что вы набираете во время исправления, не перемешивается с перепечатываемым текстом.
- После Ctrl+Tab GNOME меняет раскладку примерно за 30 мс, но ещё 130–230 мс держит клавиатуру (всплывающий переключатель раскладок). Буквы, напечатанные в этот момент, пропадают — именно так терял текст старый easy-switcher с фиксированной паузой. Программа не ждёт наугад: она проверяет у X-сервера, что раскладка сменилась **и** клавиатура освобождена, и только потом печатает.
- Каждое исправление пишется в журнал с замерами времени. Сам текст не пишется, чтобы туда не попали пароли:
  ```
  исправлено: 6 симв. (слово), раскладка 1 → 0, ожидание смены 28 мс, клавиатура занята ещё 150 мс
  ```

## Если что-то не так

- **Клавиатура перестала отвечать.** Мышью откройте терминал и выполните `systemctl --user stop easy-switcher-ng`. Если программа падает, клавиатура возвращается к обычной работе сама.
- **Слово стирается, но не печатается.** Посмотрите журнал. Если там «раскладка не сменилась», проверьте `switch_keys`.
- **Вернуть старый easy-switcher:** `sudo systemctl enable --now easy-switcher`

## Файлы в репозитории

| Файл | Назначение |
|---|---|
| `easy_switcher_ng.py` | программа |
| `config.toml` | настройки по умолчанию |
| `easy-switcher-ng.service` | systemd-служба пользователя |
| `70-easy-switcher-ng.rules` | udev: доступ к клавиатуре и мыши для активного сеанса |
| `install.sh` | установка из этих файлов (для разработки) |
| `easy-switcher-ng-setup.sh` | всё то же в одном файле — для переноса |

После изменения `easy_switcher_ng.py` или других файлов пересоберите `easy-switcher-ng-setup.sh`, иначе он останется со старой версией.

## Куда ставится

```
~/.local/share/easy-switcher-ng/                 программа и venv (evdev)
~/.config/easy-switcher-ng/config.toml           настройки
~/.config/systemd/user/easy-switcher-ng.service  автозапуск
/etc/udev/rules.d/70-easy-switcher-ng.rules      доступ к устройствам ввода
```
